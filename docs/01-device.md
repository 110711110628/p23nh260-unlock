## 芯片规格

| 项目 | 值 | 实测/来源 |
|---|---|---|
| CPU | 4×A76 + 4×A55 | 实测兼容 |
| 大核频率上限 | **2.21GHz**（cpu4-7） | `/sys/.../cpuinfo_max_freq` |
| 小核频率上限 | **2.002GHz**（cpu0-3） | 同上 |
| 小核频率下限 | 614MHz | `cpuinfo_min_freq` |
| 调度器 | `schedutil` | `scaling_governor` |
| GPU | Mali-G57 | devfreq 节点 `23140000.gpu` |
| 内存 | 8GB LPDDR4X | uboot 日志 `ddrsize 8192M` |
| 存储 | 256GB | `/data` 229GB |

> 注：官方 T770 标称最高 2.7GHz；本机固件限制在 2.21GHz（学习机功耗策略）。

## 屏幕

| 项目 | 值 |
|---|---|
| 尺寸 | 14.2 英寸 |
| 物理分辨率 | 2328 × 1600（旋转后 1600×2328） |
| 刷新率 | **仅 60Hz**（`supportedModes` 只有一种 60Hz 模式） |
| 密度 | 320dpi（物理约 190ppi） |
| HDR | 支持（类型 2/3/4） |

## 存储与分区

- 采用 **A/B 结构**（boot_a/boot_b、vendor_boot_a/b 等），
  但逻辑分区（system/product 等）**只有 _a 槽**，b 槽为空分区（A-only 逻辑布局）。
- `/data` 可用 229GB，用户数据 100GB+。

## 安全状态

| 项目 | 状态 | 说明 |
|---|---|---|
| Bootloader | **已解锁** | 通过 BROM 漏洞修改 `seccfg` |
| AVB | 启用（`vbmeta_a` flags=0） | 但解锁状态下被启动器容忍 |
| SELinux | Enforcing | 策略为 厂商 重度定制（见 04） |
| dm-verity | 已关闭 | 因为我们使用 TWRP vendor_boot（其 fstab 无 avb 参数） |
| 完整性校验 | `versiond` + `md5sum.lst` | 实际未阻断启动（见 04） |
